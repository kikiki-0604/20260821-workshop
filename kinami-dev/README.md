# Reversi Arena

React + TypeScript + Tailwind CSS で作られた、本格実装のオセロ(リバーシ)Webアプリです。
正式なオセロルールの完全実装に加え、Minimax + アルファベータ枝刈りによる4段階のAI対戦、
同一PCでの2人対戦モードを搭載しています。

## 主な機能

### 対戦モード

- **VS コンピュータ**
  - プレイヤーは黒 / 白どちらを持つか選択可能
  - 難易度は「かんたん / ふつう / つよい / 激つよ」の4段階
  - AIの手番では「考え中...」表示とともに 300〜800ms のランダムなディレイを挟んで着手
- **二人対戦（同一PCでのローカル対戦）**
  - 手番プレイヤーの色 / 名前を大きく表示し、手番交代時にアニメーションで切り替えを演出
  - 各プレイヤーの名前を任意で入力可能（未入力時は「黒」「白」）
  - 難易度・AI関連のUIは非表示

いつでも「モード選択に戻る」ボタンからモードを切り替えられます。

### ゲームルール

- 8x8盤面、正式なオセロルールを完全実装（合法手判定、石の反転、パス、勝敗/引き分け判定）
- 置ける場所がない場合は自動パスし、画面上に通知
- 両者パスでゲーム終了

### AI（VSコンピュータモード）

- Minimax + アルファベータ枝刈りを実装
- 難易度ごとに探索深さと評価関数の重みを変更
  - 角・辺の位置的価値（重みテーブル）
  - 着手可能数（モビリティ）
  - 確定石（安定石)の推定数
  - 終盤（空きマスが少ない局面）は完全読み切りで最善手を選択
- ゲームの進行度（序盤・中盤・終盤）に応じて評価関数の重みを動的に調整

### キャラクター

- 対局開始前に、ネコ・イヌ・トリ・サカナの4キャラクターから選択（VSコンピュータはプレイヤー1体、AIはランダムで自動割り当て／二人対戦は黒・白それぞれ選択）
- 石を置くたびにキャラクターの吹き出しが表示され、「ここだ！」「決まりだ！」など性格に応じたセリフがランダムに再生
- ブラウザのWeb Speech APIによる読み上げボイス付き（キャラクターごとにピッチ・速度を変えて声色を演出）。対応ボイスは端末/ブラウザの音声合成環境に依存

### BGM / サウンド

- Web Audio APIで自前合成した、まったり系ローファイ風のBGMループ（外部音源ファイル不使用）
- ヘッダーのアイコンでBGM・キャラクターボイスをそれぞれON/OFF切り替え可能（設定はブラウザに保存）

### UI/UX

- 木目調の盤面フレーム × 深緑フェルトの盤面という高級感のある見た目
- 石を置いた際の3Dフリップアニメーション（Framer Motion）
- 合法手のハイライト表示・ホバーで光るエフェクト
- 現在の手番、黒白それぞれの石数をリアルタイム表示
- 直前に置いた石の位置がわかるマーカー表示
- ゲーム終了時の紙吹雪演出 + 結果モーダル
- 「待った（一手戻す）」「新規対局」「モード選択に戻る」「難易度変更」「石の色選択」
- レスポンシブ対応（スマホ・タブレット対応）／ダークモード対応

## 技術スタック

| 分類 | 技術 |
| --- | --- |
| フレームワーク | React 18 + TypeScript |
| ビルドツール | Vite |
| スタイリング | Tailwind CSS |
| アニメーション | Framer Motion |
| AIロジック | Minimax + アルファベータ枝刈り（Web Workerで実行、自前実装） |
| BGM / ボイス | Web Audio API（自前合成） / Web Speech API（自前実装） |
| デプロイ | GitHub Actions → GitHub Pages |

外部ライブラリは React / Tailwind / Framer Motion のみに絞り、ゲームロジック・AIロジックはすべて自前実装です。

## プロジェクト構成

```
src/
  components/   UIコンポーネント（Board, Cell, Disc, ModeSelector, GameControls など）
  hooks/        useGame（ゲーム状態管理）, useDarkMode
  logic/        reversiEngine（ルール実装）, ai（AI実装）, labels（表示用ユーティリティ）
  types.ts      共通の型定義
```

ゲームロジック（`logic/`）はReactに依存しない純粋関数として実装されており、UIから独立してテスト可能です。
対戦モードの切り替えは「次の一手を人間の入力で決めるか、AIの計算で決めるか」だけを切り替える設計になっており、
盤面計算・合法手判定・石の反転処理はモードによらず完全に共通化されています。

## ローカルでの起動方法

Node.js 20 以降を推奨します。リポジトリ直下から `kinami-dev` ディレクトリに移動してから実行してください。

```bash
cd kinami-dev

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

表示されたURL（通常は `http://localhost:5173`）をブラウザで開いてください。

その他のコマンド:

```bash
# 本番ビルド
npm run build

# ビルド結果のプレビュー
npm run preview

# 型チェックのみ
npm run type-check
```

## GitHub Pagesへのデプロイ手順

このリポジトリには `main` ブランチへのpushで自動ビルド・自動デプロイされる
GitHub Actionsワークフロー（`.github/workflows/deploy.yml`）が含まれています。

1. GitHubリポジトリの **Settings → Pages** を開く
2. **Build and deployment → Source** を `GitHub Actions` に設定する
3. `main` ブランチに push する（または Actions タブから `Deploy to GitHub Pages` ワークフローを手動実行する）
4. ワークフローが完了すると、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリにアクセスできる

> `vite.config.ts` の `base` はリポジトリ名 `20260821-workshop` に合わせて `/20260821-workshop/` に設定しています。
> リポジトリ名を変更した場合はこの値も合わせて更新してください。
